# Migrate to Lovable-managed Google Sign-in

## Goal
Remove the current direct-Supabase Google OAuth call that requires you to configure the provider in an external dashboard. Replace it with the Lovable Cloud managed Google flow — credentials, redirect URIs, and provider toggles are all handled for you.

## What changes

1. **Enable managed Google auth** via the `configure_social_auth` tool with `providers: ["google"]`. This auto-generates the `src/integrations/lovable/` module and installs `@lovable.dev/cloud-auth-js`. Email/password stays enabled.
2. **Update `src/pages/Auth.tsx`** — replace the current `supabase.auth.signInWithOAuth("google", ...)` call in the "Continue with Google" button with:
   ```ts
   import { lovable } from "@/integrations/lovable";
   const result = await lovable.auth.signInWithOAuth("google", {
     redirect_uri: window.location.origin,
   });
   ```
   Handle `result.error` with a toast and `result.redirected` by returning. Email/password sign-in and sign-up are untouched.
3. **Verify** the sign-in button in the preview loads the Google popup without needing dashboard toggles.

## What you no longer need to do
- No Google Cloud Console OAuth client
- No pasting Client ID / Secret into a provider dashboard
- No manual redirect URL entries

## Files touched
- `src/pages/Auth.tsx` — swap the Google handler
- `src/integrations/lovable/*` — auto-generated by the tool (do not hand-edit)
- `package.json` — `@lovable.dev/cloud-auth-js` added by the tool
